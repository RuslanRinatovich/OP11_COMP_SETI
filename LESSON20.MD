## 1. Что такое JavaScript?

**JavaScript (JS)** – это язык программирования, который делает веб-страницы живыми.

- **HTML** – каркас (скелет) страницы.
- **CSS** – одежда и косметика (цвета, размеры, расположение).
- **JavaScript** – мышцы и нервы (реакция на действия пользователя).

Без JS страница статична. С JS она может:
- реагировать на клики, наведение мыши, ввод текста;
- менять свой вид после загрузки;
- показывать всплывающие сообщения;
- выполнять вычисления прямо в браузере.

<script src="script.js"></script>

## 3. Простейшие команды: `alert` и `console.log`

### `alert("текст")`

Показывает всплывающее окно с сообщением. Пользователь должен нажать «ОК».

```javascript
alert("Добро пожаловать на сайт!");
```

### `console.log("текст")`

Выводит сообщение в **консоль разработчика**. Обычный пользователь его не видит, но для программиста это очень полезно.

**Как открыть консоль:**
- Нажмите `F12` (или `Ctrl+Shift+I`) → вкладка **Console**.

```javascript
console.log("Это видно только в консоли");
```

## 4. Переменные и типы данных

### Что такое переменная?

Переменная – это «коробка с именем», в которой можно сохранить какое-то значение (число, текст, истину/ложь и т.д.).

### Создание переменных: `let` и `const`

- `let` – значение можно менять позже.
- `const` – значение неизменно (константа).

```javascript
let userName = "Анна";     // строка (текст)
const birthYear = 2005;    // число
let isStudent = true;      // логический тип (true/false)
```

### Основные типы данных

| Тип       | Пример           | Описание                     |
|-----------|------------------|------------------------------|
| `number`  | `42`, `3.14`     | Целые и дробные числа        |
| `string`  | `"Привет"`       | Текст в кавычках (двойных или одинарных) |
| `boolean` | `true`, `false`  | Логическое «истина» или «ложь» |
| `undefined` | `let x;`       | Переменная объявлена, но значение не задано |
| `null`    | `let y = null;`  | «Ничего», пустое значение    |

### Вывод значения переменной

```javascript
let city = "Москва";
console.log(city);               // в консоль
alert("Город: " + city);         // в всплывающее окно
```

## 6. Как найти элемент на странице и изменить его (главная магия)

Чтобы изменить текст, стиль или содержимое тега, нужно **найти этот тег из JavaScript**.

### Метод `document.querySelector()`

Позволяет найти первый элемент на странице, который подходит под CSS-селектор.

```javascript
let элемент = document.querySelector("селектор");
```

**Примеры селекторов:**
- `"#myId"` – элемент с `id="myId"`
- `".myClass"` – первый элемент с классом `myClass`
- `"p"` – первый абзац на странице

### Чтение и изменение текста (`textContent`)

```html
<p id="info">Исходный текст</p>

<script>
    let paragraph = document.querySelector("#info");
    console.log(paragraph.textContent);   // "Исходный текст"
    paragraph.textContent = "Новый текст!";
</script>
```

### Изменение стилей (`style`)

```javascript
let heading = document.querySelector("h1");
heading.style.color = "red";
heading.style.fontSize = "32px";
heading.style.backgroundColor = "yellow";
```

### Реакция на клик кнопки

```html
<button id="clickMe">Нажми меня</button>
<p id="result">Тут будет результат</p>

<script>
    let button = document.querySelector("#clickMe");
    let output = document.querySelector("#result");

    button.onclick = function() {
        output.textContent = "Кнопка была нажата!";
        output.style.color = "green";
    };
</script>
```

**Разбор:**  
- Находим кнопку и абзац.  
- Присваиваем свойству `onclick` **функцию** (код, который выполнится по клику).  
- Внутри функции меняем текст и цвет абзаца.

---

## 7. Полный работающий пример (скопируйте и запустите)

Создайте файл `index.html` и вставьте следующий код:

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Пример: меняем страницу</title>
    <style>
        body { font-family: Arial; padding: 20px; }
        .box {
            width: 200px;
            height: 100px;
            background-color: lightblue;
            margin: 20px 0;
            text-align: center;
            line-height: 100px;
        }
        button { padding: 8px 16px; margin-right: 10px; }
    </style>
</head>
<body>

    <h1 id="mainTitle">Заголовок страницы</h1>
    <div class="box" id="colorBox">Кликни на кнопку</div>
    <button id="changeTextBtn">Изменить текст</button>
    <button id="changeColorBtn">Сменить цвет</button>

    <script>
        // Находим нужные элементы
        let title = document.querySelector("#mainTitle");
        let box = document.querySelector("#colorBox");
        let textBtn = document.querySelector("#changeTextBtn");
        let colorBtn = document.querySelector("#changeColorBtn");

        // Кнопка "Изменить текст"
        textBtn.onclick = function() {
            title.textContent = "Текст изменён через JavaScript!";
            box.textContent = "Спасибо, что нажали";
        };

        // Кнопка "Сменить цвет"
        colorBtn.onclick = function() {
            box.style.backgroundColor = "orange";
            box.style.border = "2px solid black";
        };
    </script>

</body>
</html>
```

**Что произойдёт?** После загрузки нажмите на кнопки – заголовок поменяется, а блок изменит цвет и текст.
