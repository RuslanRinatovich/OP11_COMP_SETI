## 2. Условия `if/else` (25 мин)

### Зачем нужны условия?

Программа должна принимать решения в зависимости от ситуации.

- Если пользователь ввёл пароль короче 6 символов → показать ошибку.
- Если возраст больше 18 → доступ разрешён, иначе → запрещён.

### Синтаксис `if`

```javascript
if (условие) {
    // код, который выполнится, если условие истинно
}
```

### Операторы сравнения

| Оператор | Значение | Пример |
|----------|----------|--------|
| `>` | больше | `age > 18` |
| `<` | меньше | `price < 100` |
| `>=` | больше или равно | `count >= 10` |
| `<=` | меньше или равно | `score <= 5` |
| `===` | строго равно | `name === "Иван"` |
| `!==` | не равно | `password !== "123"` |

### Простой пример

```javascript
let age = 20;
if (age >= 18) {
    console.log("Доступ разрешён");
}
```

### Конструкция `if/else`

Если условие не выполняется, можно выполнить другой код.

```javascript
let age = 16;
if (age >= 18) {
    console.log("Доступ разрешён");
} else {
    console.log("Доступ запрещён. Вы слишком молоды");
}
```

### Конструкция `if/else if/else` (несколько вариантов)

```javascript
let score = 85;
if (score >= 90) {
    console.log("Отлично");
} else if (score >= 70) {
    console.log("Хорошо");
} else if (score >= 50) {
    console.log("Удовлетворительно");
} else {
    console.log("Неудовлетворительно");
}
```

### Пример с проверкой поля ввода

```html
<input type="text" id="userName" placeholder="Введите имя">
<button id="checkBtn">Проверить</button>
<p id="message"></p>

<script>
    let button = document.querySelector("#checkBtn");
    let input = document.querySelector("#userName");
    let output = document.querySelector("#message");

    button.onclick = function() {
        let name = input.value;
        if (name === "") {
            output.textContent = "Ошибка: имя не может быть пустым!";
            output.style.color = "red";
        } else {
            output.textContent = "Привет, " + name + "!";
            output.style.color = "green";
        }
    };
</script>
```

## 3. Функции (25 мин)

### Что такое функция?

Функция – это "кирпичик" кода, который можно назвать по имени и выполнить в любой момент.

**Зачем нужны функции?**
- Чтобы не писать один и тот же код много раз.
- Чтобы разбить программу на понятные части.
- Чтобы можно было запустить код по событию (клик, загрузка страницы).

### Создание (объявление) функции

```javascript
function имяФункции() {
    // код, который будет выполнен при вызове
}
```

### Вызов функции

```javascript
имяФункции();   // просто пишем имя со скобками
```

### Пример 1. Функция без параметров

```javascript
function showHello() {
    console.log("Привет, мир!");
}

showHello();   // вызовет функцию
showHello();   // можно вызвать много раз
```

### Пример 2. Функция с параметрами (входными данными)

```javascript
function greetUser(name) {
    console.log("Привет, " + name + "!");
}

greetUser("Анна");   // Привет, Анна!
greetUser("Пётр");   // Привет, Пётр!
```

### Пример 3. Функция, которая возвращает результат

```javascript
function sum(a, b) {
    let result = a + b;
    return result;   // возвращаем значение наружу
}

let total = sum(5, 3);
console.log(total);   // 8
```

### Пример 4. Функция для проверки пароля (полезно для форм)

```javascript
function isPasswordStrong(password) {
    if (password.length >= 6) {
        return true;
    } else {
        return false;
    }
}

let pwd = "12345";
if (isPasswordStrong(pwd)) {
    console.log("Пароль надёжный");
} else {
    console.log("Пароль слишком короткий");
}
```

### Функции и события (клик на кнопку)

```html
<button id="myBtn">Нажми</button>

<script>
    function sayHello() {
        alert("Здравствуйте!");
    }

    let button = document.querySelector("#myBtn");
    button.onclick = sayHello;   // обратите внимание: нет скобок!
</script>
```

**Важно:** когда привязываем функцию к событию, пишем `имяФункции` **без скобок**. Скобки означают "вызвать сейчас", а нам нужно "вызвать, когда кликнут".

## 4. Валидация форм (проверка введённых данных) (20 мин)

### Зачем проверять формы?

- Чтобы пользователь не отправил пустую форму.
- Чтобы пароль был не слишком коротким.
- Чтобы email содержал символ `@`.
- Чтобы год рождения был разумным.

### Пример 1. Проверка на пустоту

```html
<input type="text" id="email" placeholder="Введите email">
<button id="submitBtn">Отправить</button>
<p id="errorMsg"></p>

<script>
    let submit = document.querySelector("#submitBtn");
    let emailInput = document.querySelector("#email");
    let error = document.querySelector("#errorMsg");

    submit.onclick = function() {
        let email = emailInput.value;
        if (email === "") {
            error.textContent = "Пожалуйста, введите email";
            error.style.color = "red";
        } else {
            error.textContent = "Спасибо!";
            error.style.color = "green";
        }
    };
</script>
```

### Пример 2. Проверка длины пароля

```html
<input type="password" id="password" placeholder="Пароль">
<button id="checkPwd">Проверить</button>
<p id="pwdMsg"></p>

<script>
    let checkBtn = document.querySelector("#checkPwd");
    let pwdInput = document.querySelector("#password");
    let msg = document.querySelector("#pwdMsg");

    function checkPassword(pwd) {
        if (pwd.length < 6) {
            return "Слишком короткий (минимум 6 символов)";
        } else if (pwd.length > 20) {
            return "Слишком длинный (максимум 20 символов)";
        } else {
            return "Пароль подходит";
        }
    }

    checkBtn.onclick = function() {
        let password = pwdInput.value;
        let result = checkPassword(password);
        msg.textContent = result;
        
        if (result === "Пароль подходит") {
            msg.style.color = "green";
        } else {
            msg.style.color = "red";
        }
    };
</script>
```

### Пример 3. Проверка подтверждения пароля

```html
<input type="password" id="pwd1" placeholder="Пароль">
<input type="password" id="pwd2" placeholder="Подтвердите пароль">
<button id="registerBtn">Зарегистрироваться</button>
<p id="regMsg"></p>

<script>
    let regBtn = document.querySelector("#registerBtn");
    let pwdFirst = document.querySelector("#pwd1");
    let pwdSecond = document.querySelector("#pwd2");
    let regMsg = document.querySelector("#regMsg");

    regBtn.onclick = function() {
        let pass1 = pwdFirst.value;
        let pass2 = pwdSecond.value;
        
        if (pass1 === "") {
            regMsg.textContent = "Введите пароль";
        } else if (pass1 !== pass2) {
            regMsg.textContent = "Пароли не совпадают!";
        } else if (pass1.length < 6) {
            regMsg.textContent = "Пароль должен быть не короче 6 символов";
        } else {
            regMsg.textContent = "Регистрация успешна!";
            regMsg.style.color = "green";
            // Здесь можно очистить поля или отправить данные на сервер
            return;
        }
        regMsg.style.color = "red";
    };
</script>
```

### Задание 3. Проверка формы регистрации (25 минут) – главное задание

Создайте `task3.html` со следующими полями:

1. **Логин** (текстовое поле) – не менее 3 символов.
2. **Пароль** (поле типа password) – не менее 6 символов.
3. **Подтверждение пароля** (поле типа password).
4. **Email** (текстовое поле) – должен содержать символ `@` и точку `.`.

6. **Область для вывода всех ошибок** (списком или построчно).

**Что проверяем при клике на кнопку:**

| Поле | Условие | Сообщение об ошибке |
|------|---------|---------------------|
| Логин | длина < 3 | «Логин должен быть не менее 3 символов» |
| Пароль | длина < 6 | «Пароль должен быть не менее 6 символов» |
| Подтверждение | не совпадает с паролем | «Пароли не совпадают» |

**Подсказка для проверки email:**

```javascript
let email = emailInput.value;
if (!email.includes("@") || !email.includes(".")) {
    // ошибка
```
