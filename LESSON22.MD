## 2. Массивы (30 минут)

### ❓ Что такое массив?

**Массив** — это структура данных, которая позволяет хранить несколько значений в одной переменной.

**Простая аналогия:** Массив — это как многоэтажный шкаф с пронумерованными ящиками. В каждом ящике можно что-то хранить, и у каждого ящика есть номер (индекс).

### 📦 Пример без массива (плохо)

```javascript
let товар1 = "яблоко";
let товар2 = "банан";
let товар3 = "апельсин";
let товар4 = "груша";
let товар5 = "киви";
```

Если товаров 100, придётся создать 100 переменных. Это неудобно.

### 📦 Пример с массивом (хорошо)

```javascript
let товары = ["яблоко", "банан", "апельсин", "груша", "киви"];
```

Все товары хранятся в одной переменной `товары`.

### 📝 Как создать массив

Способ 1. Используя квадратные скобки `[]` (рекомендуется):

```javascript
let пустойМассив = [];
let числа = [10, 20, 30, 40, 50];
let имена = ["Анна", "Петр", "Иван", "Мария"];
let смешанный = [1, "текст", true, null];
```

Способ 2. Используя конструктор `new Array()` (реже):

```javascript
let массив = new Array(1, 2, 3);
```

> 💡 **Рекомендация:** Используйте квадратные скобки `[]` — это короче и понятнее.

### 🔢 Индексы элементов

У каждого элемента в массиве есть номер — **индекс**. **Важно:** индексы начинаются с **нуля**.

```javascript
let фрукты = ["яблоко", "банан", "апельсин", "груша"];
// индекс:     0         1          2          3
```

| Выражение | Результат | Пояснение |
|-----------|-----------|-----------|
| `фрукты[0]` | `"яблоко"` | первый элемент |
| `фрукты[1]` | `"банан"` | второй элемент |
| `фрукты[2]` | `"апельсин"` | третий элемент |
| `фрукты[3]` | `"груша"` | четвёртый элемент |
| `фрукты[4]` | `undefined` | элемента нет |

### 📏 Длина массива (свойство `length`)

Свойство `length` показывает, сколько элементов в массиве.

```javascript
let дни = ["пн", "вт", "ср", "чт", "пт", "сб", "вс"];
console.log(дни.length);  // 7

let пустой = [];
console.log(пустой.length);  // 0
```

**Важная особенность:** Индекс последнего элемента всегда равен `length - 1`.

```javascript
let цвета = ["красный", "синий", "зеленый"];
console.log(цвета.length);      // 3
console.log(цвета[2]);          // "зеленый" (последний)
console.log(цвета[цвета.length - 1]);  // "зеленый" (тоже последний)
```

### ✏️ Изменение элемента массива

```javascript
let цвета = ["красный", "синий", "зеленый"];
цвета[1] = "желтый";  // меняем второй элемент
console.log(цвета);   // ["красный", "желтый", "зеленый"]
```

### ➕ Добавление элемента в конец массива (метод `push()`)

```javascript
let животные = ["кошка", "собака"];
животные.push("хомяк");
console.log(животные);  // ["кошка", "собака", "хомяк"]

// Можно добавить несколько элементов сразу
животные.push("попугай", "рыбка");
console.log(животные);  // ["кошка", "собака", "хомяк", "попугай", "рыбка"]
```

### ➕ Добавление элемента в начало массива (метод `unshift()`)

```javascript
let числа = [2, 3, 4];
числа.unshift(1);
console.log(числа);  // [1, 2, 3, 4]
```

### ❌ Удаление последнего элемента (метод `pop()`)

```javascript
let животные = ["кошка", "собака", "хомяк"];
let удаленный = животные.pop();
console.log(животные);   // ["кошка", "собака"]
console.log(удаленный);  // "хомяк"
```

### ❌ Удаление первого элемента (метод `shift()`)

```javascript
let числа = [1, 2, 3, 4];
let удаленный = числа.shift();
console.log(числа);     // [2, 3, 4]
console.log(удаленный); // 1
```

### 📋 Таблица основных методов массивов

| Метод | Что делает | Пример | Результат |
|-------|------------|--------|-----------|
| `push(элемент)` | добавляет в конец | `arr.push(5)` | новая длина массива |
| `pop()` | удаляет последний | `arr.pop()` | удалённый элемент |
| `unshift(элемент)` | добавляет в начало | `arr.unshift(1)` | новая длина массива |
| `shift()` | удаляет первый | `arr.shift()` | удалённый элемент |
| `length` | длина массива | `arr.length` | число элементов |

## 3. Циклы (30 минут)

### ❓ Зачем нужны циклы?

Циклы позволяют выполнить один и тот же код много раз, не повторяя его вручную.

**Пример без цикла (плохо):**

```javascript
console.log(фрукты[0]);
console.log(фрукты[1]);
console.log(фрукты[2]);
console.log(фрукты[3]);
console.log(фрукты[4]);
```

Если в массиве 1000 элементов, так писать невозможно.

**Пример с циклом (хорошо):**

```javascript
for (let i = 0; i < фрукты.length; i++) {
    console.log(фрукты[i]);
}
```

### 📝 Синтаксис цикла `for`

```javascript
for (начало; условие; шаг) {
    // код, который повторяется на каждой итерации
}
```

| Часть | Что делает | Пример |
|-------|------------|--------|
| **начало** | выполняется один раз перед стартом | `let i = 0` |
| **условие** | проверяется перед каждой итерацией; если `true` — цикл продолжается | `i < 5` |
| **шаг** | выполняется после каждой итерации | `i++` (увеличить i на 1) |

### 🔄 Разбор работы цикла на пальцах

```javascript
for (let i = 0; i < 5; i++) {
    console.log("Итерация номер: " + i);
}
```

**Как это выполняется по шагам:**

| Шаг | Значение `i` | Проверка `i < 5` | Действие |
|-----|--------------|------------------|----------|
| 1 | 0 | `true` | выводим "Итерация номер: 0", затем `i++` (i становится 1) |
| 2 | 1 | `true` | выводим "Итерация номер: 1", затем `i++` (i становится 2) |
| 3 | 2 | `true` | выводим "Итерация номер: 2", затем `i++` (i становится 3) |
| 4 | 3 | `true` | выводим "Итерация номер: 3", затем `i++` (i становится 4) |
| 5 | 4 | `true` | выводим "Итерация номер: 4", затем `i++` (i становится 5) |
| 6 | 5 | `false` | цикл завершается |

**Результат:**
```
Итерация номер: 0
Итерация номер: 1
Итерация номер: 2
Итерация номер: 3
Итерация номер: 4
```

### 🔄 Цикл для перебора массива (самый частый вариант)

```javascript
let имена = ["Анна", "Петр", "Иван", "Мария", "Ольга"];

for (let i = 0; i < имена.length; i++) {
    console.log("Привет, " + имена[i] + "!");
}
```

**Результат:**
```
Привет, Анна!
Привет, Петр!
Привет, Иван!
Привет, Мария!
Привет, Ольга!
```

### 🔄 Почему мы пишем `i < имена.length`, а не `i <= имена.length`?

```javascript
let имена = ["Анна", "Петр", "Иван"];  // длина = 3
// Индексы: 0, 1, 2
```

- Если условие `i < 3`: i = 0, 1, 2 → 3 итерации ✅
- Если условие `i <= 3`: i = 0, 1, 2, 3 → имена[3] = `undefined` ❌

### 🎨 Пример: вывод массива на страницу

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Вывод массива</title>
</head>
<body>
    <h2>Список студентов</h2>
    <ul id="studentList"></ul>

    <script>
        let студенты = ["Анна", "Петр", "Иван", "Мария", "Ольга"];
        let список = document.querySelector("#studentList");
        
        for (let i = 0; i < студенты.length; i++) {
            список.innerHTML = список.innerHTML + "<li>" + студенты[i] + "</li>";
        }
    </script>
</body>
</html>
```

### 🔄 Другие виды циклов (краткий обзор)

**Цикл `while`** — выполняется, пока условие истинно:

```javascript
let i = 0;
while (i < 5) {
    console.log(i);
    i++;
}
```

**Цикл `do...while`** — выполнится хотя бы один раз:

```javascript
let i = 0;
do {
    console.log(i);
    i++;
} while (i < 5);
```

> 💡 **Рекомендация:** Для перебора массивов чаще всего используют цикл `for`.

## 4. Создание и удаление элементов на странице (20 минут)

### 🏗️ Метод `createElement`

Позволяет создать новый HTML-элемент прямо из JavaScript.

```javascript
let новыйЭлемент = document.createElement("тег");
```

**Примеры:**

```javascript
let параграф = document.createElement("p");
let кнопка = document.createElement("button");
let элементСписка = document.createElement("li");
let див = document.createElement("div");
```

### ➕ Метод `appendChild`

Добавляет созданный элемент внутрь другого элемента (в конец).

```javascript
родитель.appendChild(новыйЭлемент);
```

### ✏️ Метод `textContent`

Устанавливает текст внутри созданного элемента.

```javascript
новыйЭлемент.textContent = "Какой-то текст";
```

### 🏗️ Полный пример создания элемента

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Создание элементов</title>
</head>
<body>
    <div id="container">
        <p>Это существующий абзац</p>
    </div>
    <button id="addBtn">Добавить абзац</button>

    <script>
        let container = document.querySelector("#container");
        let button = document.querySelector("#addBtn");
        
        button.onclick = function() {
            let новыйПараграф = document.createElement("p");
            новыйПараграф.textContent = "Это новый абзац, созданный через JavaScript!";
            container.appendChild(новыйПараграф);
        };
    </script>
</body>
</html>
```

### ❌ Метод `remove()`

Удаляет элемент со страницы.

```javascript
элемент.remove();
```

### 🏗️ Пример: добавление и удаление элементов

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Добавление и удаление</title>
    <style>
        .item {
            padding: 10px;
            margin: 5px;
            background-color: lightblue;
            cursor: pointer;
        }
    </style>
</head>
<body>
    <button id="addBtn">➕ Добавить элемент</button>
    <div id="itemsContainer"></div>

    <script>
        let container = document.querySelector("#itemsContainer");
        let addButton = document.querySelector("#addBtn");
        let counter = 1;
        
        addButton.onclick = function() {
            let новыйЭлемент = document.createElement("div");
            новыйЭлемент.className = "item";
            новыйЭлемент.textContent = "Элемент #" + counter;
            
            // При клике на сам элемент удаляем его
            новыйЭлемент.onclick = function() {
                this.remove();  // this — это элемент, на который кликнули
            };
            
            container.appendChild(новыйЭлемент);
            counter++;
        };
    </script>
</body>
</html>
```

### 🏗️ Пример: To-Do список (базовая версия)

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Мой To-Do список</title>
    <style>
        body { font-family: Arial; max-width: 500px; margin: 50px auto; }
        .todo-item {
            padding: 10px;
            margin: 5px;
            background-color: #f0f0f0;
            display: flex;
            justify-content: space-between;
            align-items: center;
        }
        .delete-btn {
            background-color: red;
            color: white;
            border: none;
            padding: 5px 10px;
            cursor: pointer;
        }
        input, button { padding: 10px; margin: 5px; }
    </style>
</head>
<body>
    <h2>📝 Список дел</h2>
    <input type="text" id="taskInput" placeholder="Новое дело...">
    <button id="addTaskBtn">Добавить</button>
    <div id="todoList"></div>

    <script>
        let input = document.querySelector("#taskInput");
        let addBtn = document.querySelector("#addTaskBtn");
        let todoList = document.querySelector("#todoList");
        
        function createTodoItem(text) {
            let itemDiv = document.createElement("div");
            itemDiv.className = "todo-item";
            
            let textSpan = document.createElement("span");
            textSpan.textContent = text;
            
            let deleteBtn = document.createElement("button");
            deleteBtn.textContent = "✖ Удалить";
            deleteBtn.className = "delete-btn";
            
            deleteBtn.onclick = function() {
                itemDiv.remove();  // удаляем родительский div
            };
            
            itemDiv.appendChild(textSpan);
            itemDiv.appendChild(deleteBtn);
            
            return itemDiv;
        }
        
        addBtn.onclick = function() {
            let taskText = input.value.trim();  // trim() удаляет пробелы в начале и конце
            
            if (taskText === "") {
                alert("Пожалуйста, введите текст дела!");
                return;
            }
            
            let newItem = createTodoItem(taskText);
            todoList.appendChild(newItem);
            input.value = "";  // очищаем поле ввода
            input.focus();     // устанавливаем курсор в поле ввода
        };
        
        // Добавляем возможность добавлять дела по нажатию Enter
        input.addEventListener("keypress", function(event) {
            if (event.key === "Enter") {
                addBtn.click();
            }
        });
    </script>
</body>
</html>
```

**Ожидаемый результат:**

| 1×1=1 | 1×2=2 | ... | 1×10=10 |
|-------|-------|-----|---------|
| 2×1=2 | 2×2=4 | ... | 2×10=20 |
| ...   | ...   | ... | ...     |
| 10×1=10 | 10×2=20 | ... | 10×10=100 |

**Подсказка для вложенного цикла:**

```javascript
let tableHTML = "";
for (let i = 1; i <= 10; i++) {
    tableHTML += "<tr>";
    for (let j = 1; j <= 10; j++) {
        tableHTML += "<td>" + i + "×" + j + "=" + (i * j) + "</td>";
    }
    tableHTML += "</tr>";
}
document.querySelector("#tableContainer").innerHTML = "<table border='1'>" + tableHTML + "</table>";
```
